# Quote of the Day

A static quote-of-the-day page built with plain HTML, CSS, and JavaScript.

## Run

Open `index.html` in a browser. No server, package installation, or build step is
required.

## Behavior

- Shows one random quote from the built-in collection when opened.
- “New quote” selects a different quote.
- Favorites can be added, removed, and revisited from the favorites list.
- Favorites persist in this browser using `localStorage`.

The specification and implementation plan are in
`.specify/specs/001-quote-of-the-day/`.
