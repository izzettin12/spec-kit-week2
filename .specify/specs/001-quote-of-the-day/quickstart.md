# Quickstart: Quote of the Day

## Prerequisites

- A current desktop or mobile browser.
- No account, server, package installation, or network connection.

## Run

Open `index.html` directly in the browser.

## Validate the feature

1. Confirm one quote, its attribution, a “New quote” control, and the favorite
   control appear on load.
2. Activate “New quote”; confirm the displayed quote changes.
3. Favorite the active quote; confirm the favorite list and toggle state update.
4. Reload the page; confirm the favorite remains listed.
5. Select the saved quote; confirm it becomes active and remains favorited.
6. Remove it from favorites; confirm it disappears from the list.
7. With browser storage unavailable, try a favorite change; confirm an
   accessible error is shown and the page does not claim it was saved.
8. At 320 px and 1280 px widths, check that there is no horizontal overflow.
   Use Tab and Enter/Space to verify keyboard access and visible focus.
