# Week 3 assignments

This folder contains work for both Week 3 tracks:

- `prompting-techniques/` contains the four Ollama exercises and a writeup.
- `gemini-cli-dissection/` contains the Gemini CLI lab, captured evidence, and writeup.

The course assignment and its setup instructions are in the
[Week 3 assignment folder](https://github.com/scottyUX/Software-engineering-in-the-age-of-ai/tree/main/assignments/03-anatomy-of-coding-agents).

All four prompting-technique checks have been run locally with Ollama and
`llama3.1:8b`; observed results are recorded in that track's writeup. The Gemini
dissection was run with Gemini CLI `0.64.0`; its independent final test run passed
with 22 tests. Redacted evidence and the writeup are in that track's `work/` folder.
The raw `work/telemetry.log` is intentionally excluded from Git because it contains
account and prompt data.
